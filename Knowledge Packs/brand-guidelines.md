## What this page uses

Trackside palette, not a tech-startup palette:

| Name | Hex | Use on the logbook |
|---|---|---|
| Dark Asphalt | `#120404` | Page background |
| Nitro Cream | `#fef8ea` | Timeslip sheet |
| Faded Red | `#cf2125` | Sheet rule, primary button |
| Nitro Gold | `#fcc83c` | Small brand line, links |
| Sunbaked Orange | `#e88e28` | Eyebrow |
| Worn Navy | `#2e5089` | Table labels, card rule |
| Warm Metal | `#a2938d` | Secondary text |

Type is **Saira**. The car name is Bold Italic, uppercase. One voice: short, mechanical, specific.

## Do not

Banned words include epic, ultimate, insane, unleash, next-level, game-changer, buckle up, and "experience the thrill". One exclamation point per page at most. No neon, glow, or casino light. No invented driver, sponsor, or livery. No fake NHRA shield.

The car id from telemetry is the nameplate. A content-id string is not a license to attach a real driver's history.
